Function pedersen_commitment

pub fn pedersen_commitment<let N: u32>(input: [Field; N]) -> EmbeddedCurvePoint

Returns the Pedersen commitment to input, a point on the embedded curve.

The commitment is input[0] * G[0] + ... + input[N - 1] * G[N - 1], where the generators G[i] are fixed points derived by derive_generators from the domain separator "DEFAULT_DOMAIN_SEPARATOR". Nobody knows a discrete-log relation between the generators, so the commitment is binding. It is not hiding unless one of the inputs is a random blinding value.

The commitment does not include the input length, and a zero input adds nothing to the sum, so inputs that differ only by trailing zeros have the same commitment. Use pedersen_hash, which does include the length, when inputs of different lengths must not collide.

Only available when compiling for the BN254 field.

Example:

use std::hash::pedersen_commitment;

let commitment = pedersen_commitment([1, 2]);
assert(commitment != pedersen_commitment([2, 1]));

// Trailing zeros don't change the commitment.
assert_eq(pedersen_commitment([1, 2]), pedersen_commitment([1, 2, 0]));
