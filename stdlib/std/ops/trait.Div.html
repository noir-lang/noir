The / operator.

Implemented for Field and the integer types.

  • For integers, the quotient is rounded toward zero, so -7 / 2 is -3.
  • For Field, a / b is the field element c with c * b == a: it multiplies by the inverse of b, and doesn't round. 1 / 2 is not zero.

Dividing by zero fails, for Field as well as for integers. For a signed type, dividing the minimum value by -1 also fails, because the result doesn't fit. The remainder of integer division is given by Rem.

Example:

assert_eq(7_u8 / 2, 3);
assert_eq(-7_i8 / 2, -3);

// Field division multiplies by the inverse.
let half: Field = 1 / 2;
assert_eq(half * 2, 1);

Division by zero fails, for Field too:

let zero: Field = 0;
// Fails: division by zero.
let _ = 1 / zero;
