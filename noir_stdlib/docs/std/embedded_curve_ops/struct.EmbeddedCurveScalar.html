Struct EmbeddedCurveScalar

pub struct EmbeddedCurveScalar {
    pub lo: Field,
    pub hi: Field,
}

Scalar for the embedded curve represented as low and high limbs By definition, the scalar field of the embedded curve is base field of the proving system curve. It may not fit into a Field element, so it is represented with two Field elements; its low and high limbs.

The scalar's value is lo + hi * 2^128. Each limb must be less than 2^128, and the value must be less than the embedded curve's order; multi_scalar_mul fails at execution otherwise. Constructing a scalar does not check either condition.

Example:

use std::embedded_curve_ops::EmbeddedCurveScalar;

let scalar = EmbeddedCurveScalar::from_field(5);
assert_eq(scalar, EmbeddedCurveScalar::new(5, 0));

Create a new scalar using the provided (lo, hi) pair

The limbs are not checked to be less than 2^128.

Example:

use std::embedded_curve_ops::EmbeddedCurveScalar;

// 2^128 + 3
let scalar = EmbeddedCurveScalar::new(3, 1);
assert_eq(scalar, EmbeddedCurveScalar::from_field(0x100000000000000000000000000000003));
pub fn from_field(scalar: Field) -> Self

Create a scalar from the given bn254 field value

The value is split into its low and high 128 bits. The split is fully constrained: both limbs are range checked, and they are checked to be the canonical decomposition of scalar. Every Field is a valid scalar, because the BN254 scalar field is smaller than the Grumpkin scalar field. Only available when compiling for the BN254 field.

Example:

use std::embedded_curve_ops::EmbeddedCurveScalar;

let scalar = EmbeddedCurveScalar::from_field(0x100000000000000000000000000000003);
assert_eq(scalar.lo, 3);
assert_eq(scalar.hi, 1);
