Struct EmbeddedCurvePoint

pub struct EmbeddedCurvePoint {
    pub x: Field,
    pub y: Field,
}

A point on the embedded elliptic curve By definition, the base field of the embedded curve is the scalar field of the proof system curve, i.e the Noir Field. x and y denotes the Weierstrass coordinates of the point.

For BN254 the embedded curve is Grumpkin, y^2 = x^3 - 17. The point at infinity is represented as (0, 0), which is not otherwise on the curve.

Constructing a point does not check that it is on the curve. embedded_curve_add and multi_scalar_mul fail at execution if an input is neither on the curve nor (0, 0).

Example:

use std::embedded_curve_ops::EmbeddedCurvePoint;

let g = EmbeddedCurvePoint::generator();
let two_g = g + g;
assert_eq(two_g, g.double());
assert_eq(two_g - g, g);
assert((g - g).is_infinite());

pub fn double(self) -> Self

Elliptic curve point doubling operation returns the doubled point of a point P, i.e P+P

Example:

use std::embedded_curve_ops::EmbeddedCurvePoint;

let g = EmbeddedCurvePoint::generator();

Failures

Fails at execution if self is neither on the curve nor the point at infinity.

pub fn point_at_infinity() -> Self

Returns the null element of the curve; 'the point at infinity'

It is represented as (0, 0).

Example:

use std::embedded_curve_ops::EmbeddedCurvePoint;

let g = EmbeddedCurvePoint::generator();
let infinity = EmbeddedCurvePoint::point_at_infinity();
assert(infinity.is_infinite());
assert_eq(g + infinity, g);
pub fn generator() -> Self

Returns the curve's generator point.

This is the Grumpkin generator (1, sqrt(-16)), the base point of fixed_base_scalar_mul.

Example:

use std::embedded_curve_ops::{EmbeddedCurvePoint, EmbeddedCurveScalar, fixed_base_scalar_mul};

let g = EmbeddedCurvePoint::generator();
assert_eq(g.x, 1);
assert_eq(fixed_base_scalar_mul(EmbeddedCurveScalar::new(1, 0)), g);
pub fn is_infinite(self) -> bool

True if this point is the point at infinity

use std::embedded_curve_ops::EmbeddedCurvePoint;

assert(EmbeddedCurvePoint::point_at_infinity().is_infinite());
