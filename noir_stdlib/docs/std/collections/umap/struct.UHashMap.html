Struct UHashMap

pub struct UHashMap<K, V, B>
{ /* private fields */ }

A hash map for unconstrained and comptime code, mapping keys of type K to values of type V.

It is a hash table with open addressing and linear probing that grows as needed. Keys are hashed with hashers built by B, a BuildHasher. A weak hasher only makes lookups slower; it doesn't make results wrong.

All methods are unconstrained, except the constructors with_hasher, with_hasher_and_capacity and Default::default. Calling them from constrained code needs an unsafe block, and their results are not constrained afterward: nothing proves, for example, that a value returned by get was inserted under that key. Check any result that constrained code relies on. Comparing two maps with == fails in constrained code.

The standard library has no public hasher, so this example defines a minimal one, MyHasher. The examples on this type's methods use it too. Real code should use a well-distributed hasher, such as poseidon::poseidon2::Poseidon2Hasher from the poseidon library.

Example:

use std::collections::umap::UHashMap;
use std::hash::{BuildHasherDefault, Hasher};

unconstrained fn main() {
    let mut map: UHashMap<Field, Field, BuildHasherDefault<MyHasher>> = UHashMap::default();
    let _ = map.insert(1, 10);
    let _ = map.insert(2, 20);

    assert_eq(map.len(), 2);
    assert_eq(map.get(1), Option::some(10));
    assert(map.get(3).is_none());

    map.remove(1);
    assert(!map.contains_key(1));
}

// A minimal hasher, also used by the examples on this type's methods.
struct MyHasher {
    state: Field,
}

impl Hasher for MyHasher {
    fn finish(self) -> Field {
        self.state
    }

    fn write(&mut self, input: Field) {
        self.state = self.state * 31 + input;
    }
}

impl Default for MyHasher {
    fn default() -> Self {
        MyHasher { state: 0 }
    }
}

pub unconstrained fn iter_mut(&mut self, f: fn(K, V) -> (K, V))
where K: Eq, K: Hash, B: BuildHasher

For each key-value entry applies mutator function.

The map is rebuilt from the returned pairs. If f returns the same key for two entries, only one of them is kept.

Example:

MyHasher is the hasher defined in the UHashMap example.

use std::collections::umap::UHashMap;
use std::hash::BuildHasherDefault;

unconstrained fn main() {
    let mut map: UHashMap<Field, Field, BuildHasherDefault<MyHasher>> = UHashMap::default();
    let _ = map.insert(1, 10);
    map.iter_mut(|key, value| (key + 100, value * 2));
    assert_eq(map.get(101), Option::some(20));

    // Entries mapped to the same key collapse into one.
    let _ = map.insert(2, 20);
    map.iter_mut(|_key, value| (0, value));
    assert_eq(map.len(), 1);
}

pub unconstrained fn capacity(&self) -> u32

Get the current capacity of the inner table.

Before each insertion, the table doubles if len() + 1 is at least half the capacity, so the capacity is always more than the number of entries.

Example:

MyHasher is the hasher defined in the UHashMap example.

use std::collections::umap::UHashMap;
use std::hash::BuildHasherDefault;

unconstrained fn main() {
    let mut map: UHashMap<Field, Field, BuildHasherDefault<MyHasher>> = UHashMap::default();
    let _ = map.insert(1, 10);
    assert(map.capacity() > map.len());
}
