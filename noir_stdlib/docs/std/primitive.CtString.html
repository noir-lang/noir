Primitive type CtString

A a compile-time, dynamically-sized string type.

Compared to str<N> and fmtstr<N, T>, CtString is useful because its size does not need to be specified in its type. This can be used for formatting items at compile-time or general string handling in comptime code.

Since fmtstrs can be converted into CtStrings, you can make use of their formatting abilities in CtStrings by formatting in fmtstrs then converting the result to a CtString afterward.

Implementations

impl CtString

pub comptime fn new() -> Self

Returns an empty CtString.

Example:

use std::meta::ctstring::AsCtString;

comptime {
    let empty = CtString::new();
    assert_eq(empty.append_str("abc"), "abc".as_ctstring());
}
pub comptime fn append_str<let N: u32>(self, s: str<N>) -> Self

Returns a new CtString with s appended to the end.

Example:

use std::meta::ctstring::AsCtString;

comptime {
    let greeting = "hello".as_ctstring().append_str(" world");
    assert_eq(greeting, "hello world".as_ctstring());
}
pub comptime fn append_fmtstr<let N: u32, T>(self, s: fmtstr<N, T>) -> Self

Returns a new CtString with the formatted string s appended to the end.

Values interpolated into s are formatted the same way as in println, so a Field is written in hexadecimal.

Example:

use std::meta::ctstring::AsCtString;

comptime {
    let count = 3_u32;
    let message = "count: ".as_ctstring().append_fmtstr(f"{count}");
    assert_eq(message, "count: 3".as_ctstring());
}
pub comptime fn as_quoted_str(self) -> Quoted

Returns this string as a quoted string literal.

A CtString can't be converted to a str<N> directly, because its length isn't known in its type. Insert the literal with a macro call instead: foo.as_quoted_str!().

Example:

use std::meta::ctstring::AsCtString;

comptime {
    let name = "foo".as_ctstring().append_str("bar");
    let name_str: str<6> = name.as_quoted_str!();
    assert_eq(name_str, "foobar");
}
