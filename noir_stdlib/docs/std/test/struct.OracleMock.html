A mock for an oracle, for use in nargo test.

Creating a mock makes calls to the named oracle return values set by the test, instead of calling an external oracle resolver. Mocks only work in tests run by nargo test, and all of their methods are unconstrained.

Example:

use std::test::OracleMock;

#[oracle(get_value)]
unconstrained fn get_value(x: Field) -> Field {}

unconstrained fn main() {
    let mock = OracleMock::mock("get_value").returns(42);
    assert_eq(get_value(1), 42);
    assert_eq(mock.times_called(), 1);
}

impl OracleMock

pub unconstrained fn mock<let N: u32>(name: str<N>) -> Self

Creates a mock for the oracle called name.

Until it is cleared or reaches its OracleMock::times limit, the mock answers the calls to that oracle that match its parameters (see OracleMock::with_params). When several mocks match a call, the one created first answers it.

Example:

use std::test::OracleMock;

#[oracle(get_value)]
unconstrained fn get_value(x: Field) -> Field {}

unconstrained fn main() {
    let _first = OracleMock::mock("get_value").returns(1);
    let _second = OracleMock::mock("get_value").returns(2);
    // `_first` was created first, so it answers.
    assert_eq(get_value(0), 1);
}
pub unconstrained fn with_params<P>(self, params: P) -> Self

Makes the mock answer only calls whose arguments equal params.

For an oracle with several parameters, pass them as a tuple. For a single parameter, the value and a one-element tuple ((1,)) are equivalent.

Example:

use std::test::OracleMock;

#[oracle(get_value)]
unconstrained fn get_value(x: Field) -> Field {}

unconstrained fn main() {
    let _mock = OracleMock::mock("get_value").with_params(1).returns(10);
    assert_eq(get_value(1), 10);
}
pub unconstrained fn get_last_params<P>(self) -> P

Returns the arguments of the most recent call answered by this mock.

Example:

use std::test::OracleMock;

#[oracle(get_value)]
unconstrained fn get_value(x: Field) -> Field {}

unconstrained fn main() {
    let mock = OracleMock::mock("get_value").returns(0);
    let _ = get_value(7);
    assert_eq(mock.get_last_params::<Field>(), 7);
}
pub unconstrained fn returns<R>(self, returns: R) -> Self

Sets the value the mock returns. Calling it again replaces that value.

Example:

use std::test::OracleMock;

#[oracle(get_value)]
unconstrained fn get_value(x: Field) -> Field {}

unconstrained fn main() {
    let mock = OracleMock::mock("get_value").returns(42);
    assert_eq(get_value(1), 42);
    let _ = mock.returns(43);
    assert_eq(get_value(1), 43);
}
pub unconstrained fn times(self, times: u64) -> Self

Limits how many calls the mock answers. After answering that many calls, the mock is removed, as if OracleMock::clear had been called.

Example:

use std::test::OracleMock;

#[oracle(get_value)]
unconstrained fn get_value(x: Field) -> Field {}

unconstrained fn main() {
    let _first = OracleMock::mock("get_value").returns(1).times(2);
    let _second = OracleMock::mock("get_value").returns(2);
    assert_eq(get_value(0), 1);
    assert_eq(get_value(0), 1);
    // `_first` has answered twice and is removed, so `_second` answers.
    assert_eq(get_value(0), 2);
}
pub unconstrained fn clear(self)

Removes the mock, so it no longer answers calls.

Example:

use std::test::OracleMock;

#[oracle(get_value)]
unconstrained fn get_value(x: Field) -> Field {}

unconstrained fn main() {
    let mock = OracleMock::mock("get_value").returns(42);
    assert_eq(get_value(1), 42);
    mock.clear();
}
pub unconstrained fn times_called(self) -> Field

Returns how many calls this mock has answered.

Example:

use std::test::OracleMock;

#[oracle(get_value)]
unconstrained fn get_value(x: Field) -> Field {}

unconstrained fn main() {
    let mock = OracleMock::mock("get_value").returns(42);
    let _ = get_value(1);
    let _ = get_value(2);
    assert_eq(mock.times_called(), 2);
}
