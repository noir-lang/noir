Struct Option

pub struct Option<T>
{ /* private fields */ }

Represents a value of type T or its absence. Use Option::some(value) to construct a value or Option::none() to record the absence of one.

Option is in the prelude. A None still holds a value of type T internally, and only Option::unwrap_unchecked exposes it. Option::none() sets it to the zeroed value of T, but nothing constrains it in general: an Option returned by unconstrained code or passed in as a program input can hold any value in a None. Option implements Eq, Ord (with None less than any Some), Hash and Default (returning None).

Example:

fn find_even(values: [u32; 3]) -> Option<u32> {
    let mut result = Option::none();
    for value in values {
        if result.is_none() & (value % 2 == 0) {
            result = Option::some(value);
        }
    }
    result
}

fn main() {
    assert_eq(find_even([1, 4, 6]), Option::some(4));
    assert(find_even([1, 3, 5]).is_none());
}

pub fn unwrap_unchecked(self) -> T

Returns the inner value without asserting self.is_some() Note that if self is None, there is no guarantee what value will be returned, only that it will be of type T.

Use it only where self.is_some() has already been established, for example to avoid repeating an assertion.

Example:

fn value_or_zero(x: Option<u32>) -> u32 {
    if x.is_some() {
        x.unwrap_unchecked()
    } else {
        0
    }
}

fn main() {
    assert_eq(value_or_zero(Option::some(5)), 5);
    assert_eq(value_or_zero(Option::none()), 0);
}

pub fn and_then<U, Env>(self, f: fn[Env](T) -> Option<U>) -> Option<U>

If self is None, this returns None. Otherwise, this calls the given function with the Some value contained within self, and returns the result of that call.

In some languages this function is called flat_map or bind.

Example:

let halve = |x: u32| if x % 2 == 0 { Option::some(x / 2) } else { Option::none() };
assert_eq(Option::some(8).and_then(halve), Option::some(4));
assert(Option::some(3).and_then(halve).is_none());

pub fn xor(self, other: Self) -> Self

If only one of the two Options is Some, return that option. Otherwise, if both options are Some or both are None, None is returned.

Example:

assert_eq(Option::some(1).xor(Option::none()), Option::some(1));
assert(Option::some(1).xor(Option::some(2)).is_none());
assert(Option::<u32>::none().xor(Option::none()).is_none());
