Function decompose

pub fn decompose(x: Field) -> (Field, Field)

Decompose a single field into two 16 byte fields.

Returns (lo, hi) with x == lo + hi * 2^128, where lo and hi are each less than 2^128. The decomposition is fully constrained and canonical: it is checked to be less than the BN254 modulus, so there is exactly one valid (lo, hi) for each x.

The functions in this module use the BN254 modulus, so they are only meaningful when compiling for the BN254 field.

Example:

let (lo, hi) = std::field::bn254::decompose(0x100000000000000000000000000000003);
assert_eq(lo, 3);
assert_eq(hi, 1);
