Function pedersen_commitment_with_separator

pub fn pedersen_commitment_with_separator<let N: u32>(
    input: [Field; N],
    separator: u32,
) -> EmbeddedCurvePoint

Returns the Pedersen commitment to input, using the generators starting at index separator.

The commitment is input[0] * G[separator] + ... + input[N - 1] * G[separator + N - 1], and pedersen_commitment is this function with a separator of 0. All the generators come from one sequence derived from "DEFAULT_DOMAIN_SEPARATOR", so separator is a generator offset, not domain separation: commitments with different separators share generators and can be equal for different inputs. A commitment with separator 1 equals a commitment with separator 0 whose input has an extra leading zero. Like pedersen_commitment, the commitment does not include the input length.

Only available when compiling for the BN254 field.

Example:

use std::hash::{pedersen_commitment, pedersen_commitment_with_separator};

let x = 42;
assert_eq(pedersen_commitment_with_separator([x], 0), pedersen_commitment([x]));

// Separator 1 starts one generator later, so it matches a leading zero at separator 0.
assert_eq(pedersen_commitment_with_separator([x], 1), pedersen_commitment([0, x]));

Failures

Fails to compile if separator is not a compile-time constant.
