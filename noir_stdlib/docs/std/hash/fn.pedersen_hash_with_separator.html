Function pedersen_hash_with_separator

pub fn pedersen_hash_with_separator<let N: u32>(
    input: [Field; N],
    separator: u32,
) -> Field

Returns the Pedersen hash of input, using the generators starting at index separator.

The hash is the x-coordinate of input[0] * G[separator] + ... + input[N - 1] * G[separator + N - 1] + N * L, with the generators G[i] and L of pedersen_hash, which is this function with a separator of 0. All the generators come from one sequence derived from "DEFAULT_DOMAIN_SEPARATOR", so separator is a generator offset, not domain separation, and hashes with different separators can collide: [0, x] with separator 0 and [x, 0] with separator 1 have the same hash, because both compute x * G[1] + 2 * L. Don't use different separators to keep hashes of different kinds of data apart; include a distinct tag in the input instead, at the same position for every kind.

Only available when compiling for the BN254 field.

Example:

use std::hash::{pedersen_hash, pedersen_hash_with_separator};

let x = 42;
assert_eq(pedersen_hash_with_separator([x], 0), pedersen_hash([x]));

// Different separators are not independent hash functions.
assert_eq(pedersen_hash_with_separator([0, x], 0), pedersen_hash_with_separator([x, 0], 1));

Failures

Fails to compile if separator is not a compile-time constant.
