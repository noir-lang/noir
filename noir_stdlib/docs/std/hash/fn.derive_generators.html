Function derive_generators

pub fn derive_generators<let N: u32, let M: u32>(
    domain_separator_bytes: [u8; M],
    starting_index: u32,
) -> [EmbeddedCurvePoint; N]

Derives N generator points on the embedded curve from a domain separator.

The points are generators starting_index to starting_index + N - 1 of the sequence for domain_separator_bytes. Generator i is obtained by hashing the BLAKE3 hash of domain_separator_bytes together with the index i onto the curve, so nobody knows a discrete-log relation between any two generators. The same domain separator and index always give the same point, and the generators for different domain separators are independent. pedersen_commitment and pedersen_hash use the domain separator "DEFAULT_DOMAIN_SEPARATOR".

Only available when compiling for the BN254 field.

Example:

use std::embedded_curve_ops::EmbeddedCurvePoint;
use std::hash::derive_generators;

let generators: [EmbeddedCurvePoint; 2] = derive_generators("my_domain".as_bytes(), 0);
assert(generators[0] != generators[1]);

// Starting one index later gives the same sequence shifted by one.
let shifted: [EmbeddedCurvePoint; 1] = derive_generators("my_domain".as_bytes(), 1);
assert_eq(shifted[0], generators[1]);

Failures

Fails to compile if domain_separator_bytes or starting_index is not a compile-time constant.
