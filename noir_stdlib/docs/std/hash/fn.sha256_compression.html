Function sha256_compression

pub fn sha256_compression(input: [u32; 16], state: [u32; 8]) -> [u32; 8]

Applies the SHA-256 compression function to one 512-bit message block.

input is the 16-word message block and state is the 8-word hash state; the result is the next hash state. Words are big-endian, as in FIPS 180-4.

This is only the compression function, not the SHA-256 hash: it does no padding and no length encoding, and processes exactly one block. To hash arbitrary bytes, use the sha256 library, which is built on this function.

Example:

// The single padded block for the message "abc".
let mut block = [0; 16];
block[0] = 0x61626380; // "abc" followed by the 0x80 padding byte
block[15] = 24; // message length in bits

// The SHA-256 initial hash state.
let iv = [
    0x6a09e667, 0xbb67ae85, 0x3c6ef372, 0xa54ff53a, 0x510e527f, 0x9b05688c, 0x1f83d9ab,
    0x5be0cd19,
];

// For a one-block message, compressing the padded block gives the SHA-256 digest.
let digest = std::hash::sha256_compression(block, iv);
assert_eq(
    digest,
    [
        0xba7816bf, 0x8f01cfea, 0x414140de, 0x5dae2223, 0xb00361a3, 0x96177a9c, 0xb410ff61,
        0xf20015ad,
    ],
);
