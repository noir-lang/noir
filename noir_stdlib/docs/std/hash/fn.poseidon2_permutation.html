Function poseidon2_permutation

pub fn poseidon2_permutation<let N: u32>(input: [Field; N]) -> [Field; N]

Applies the Poseidon2 permutation to input.

The state size N must equal the Poseidon2 state size for the field being compiled for, which is 4 for BN254. This is only the permutation, not a Poseidon2 hash: to hash a sequence of fields, use the poseidon library, which builds a sponge on this function.

Example:

let state = std::hash::poseidon2_permutation([0, 1, 2, 3]);
assert_eq(state[0], 0x01BD538C2EE014ED5141B29E9AE240BF8DB3FE5B9A38629A9647CF8D76C01737);

Failures

Fails to compile if N is not the Poseidon2 state size.
