Function aes128_encrypt

pub fn aes128_encrypt<let N: u32>(
    input: [u8; N],
    iv: [u8; 16],
    key: [u8; 16],
) -> [u8; (N + 16) - (N % 16)]

Given a plaintext as an array of bytes, returns the corresponding aes128 ciphertext (CBC mode). Input padding is performed using PKCS#7, so that the output length is input.len() + (16 - input.len() % 16).

An input whose length is already a multiple of 16 gets a full extra block of padding. The function only encrypts: it does not authenticate the ciphertext, and the caller is responsible for choosing a fresh, unpredictable iv for each encryption with the same key.

Example:

let input = "kevlovesrust".as_bytes();
let iv = "0000000000000000".as_bytes();
let key = "0000000000000000".as_bytes();

let ciphertext = std::aes128::aes128_encrypt(input, iv, key);
assert_eq(
    ciphertext,
    [244, 14, 126, 172, 171, 40, 208, 186, 173, 184, 226, 105, 238, 122, 205, 191],
);
