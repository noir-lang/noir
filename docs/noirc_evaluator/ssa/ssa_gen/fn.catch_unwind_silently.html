Function catch_unwind_silently

Source 
fn catch_unwind_silently<R>(f: impl FnOnce() -> R) -> Result<R>
Expand description

Runs f, catching a panic without printing it.

The panic hook is shared by every thread, so it must not be swapped per call while other threads may panic. One wrapper hook is installed, once, around whichever hook was set before it. The wrapper stays quiet on a thread that is inside this function and passes every other panic on. A hook set after the first call replaces the wrapper; panics inside this function are then printed.
