Compute the entry state for a block.

Starts from the exit state of the first visited predecessor (a cheap persistent clone): in RPO at least one non-back-edge predecessor has been visited, and all visited predecessors agree on every variable that is visible here and has no block parameter here (otherwise this block would be in that variable’s IDF). Then:

  • variables declared in this block map to their own allocate result as a placeholder, which abstract_interpret_block replaces when it processes the initial Store;
  • variables with a block parameter here (params) get a fresh block parameter.

With no visited predecessor (the entry block) the state starts empty.
