Module fmt_line_comments

Source
Expand description

Verify that line comments never cause the formatter to swallow code.

The AST fuzzer generates a valid program, which is formatted once to establish a normalized baseline. We then insert a line comment at a fuzz-selected token boundary, format again, and require the non-comment token stream to remain equal to the baseline. This catches both invalid formatter output and the more dangerous case where swallowed code still parses.
