Expand description

Describe every expression that had instantiation bindings when the check began and no longer has the same ones.

Expressions the check has not seen before are ignored. Monomorphization builds HIR for the values comptime evaluation produced for globals, and each Value::Function it lowers pushes a fresh expression and stores that function’s bindings against it. Those are new nodes carrying their own state, reachable only from themselves; a compilation that never sees them cannot be affected by them, which is not true of a change to an expression that was already there.
