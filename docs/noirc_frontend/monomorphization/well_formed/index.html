Checks on the shape of the program monomorphization produced.

A malformed program is wrong in a way that reads as valid all the way into SSA generation, because the identifiers involved are plain integers that index into a Vec: a function id that is off by one does not fail to resolve, it resolves to a different function.

Run in debug builds.
