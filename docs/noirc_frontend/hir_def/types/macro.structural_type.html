Macro structural_type

Source 
macro_rules! structural_type {
    () => { ... };
}
Expand description

Matches the Type variants whose nested types are all reached by Type::any_child, Type::for_each_child, Type::for_each_child_mut and Type::map_children.

The variants not listed here hold something those helpers skip:

  • Type::TypeVariable and Type::NamedGeneric: the binding
  • Type::Alias: the aliased type (only the generic arguments are children)
  • Type::DataType: the fields and variants (only the generic arguments are children)
  • Type::Forall: the bound type variables (only the body is a child)

A recursive walker over Type should match those variants by name and use this macro for the rest instead of a _ arm, so that the compiler asks it what to do with every skipped payload, including the payload of any variant added later.
